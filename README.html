二、怎么用

场景 1：只想玩 / 发给朋友

打开 游戏/神金海豹大作战_v2.html 就行。手机可以把文件传到微信、用浏览器打开；也可以在电脑上双击，或拖进浏览器窗口。

场景 2：想改内容（改皮肤、改数值、改文案）

  1. 先看 源码/v2-extension.js，搜索对应配置：
    • SKINS = [ ... ] —— 皮肤的名字、价格、稀有度
    • BOSS_DEFS = [ ... ] —— 三个 Boss 的名字、血量相关、技能类型
    • UPGRADES = [ ... ] —— 局内进化的 8 种强化
    • WIN_CAP / WORLD_SCALE / FISH_SCALE —— 体型上限、地图大小、鱼的大小
  2. 想换图片：把新图覆盖到 素材/skins/ 或 素材/boss/（文件名要保持一致）
  3. 重新构建（见场景 3）

场景 3：重新生成游戏文件

需要 Python 3 + Pillow（pip install pillow）。把 源码/merge.py 和原版源码放在一起，改好路径后运行：

python3 merge.py

脚本会自动完成：贴图转 WebP 压缩 → 抠底裁边（用于皮肤）→ 把扩展层注入原版 → 输出单文件游戏。

无尽模式

开始界面点 ∞ 无尽模式（按钮会高亮）→ 选难度 → 点「开始游戏」。 先照常打 3 个 Boss，打完不结束，屏幕中央弹出「无尽奶龙」+「无尽第N颗星」提示，随即进入无尽循环：

星数Boss 波次
第 1 颗星随机 1 个 Boss（1 波）
第 2 颗星随机 2 个 Boss 同时出现，重复 3 轮（累计 6 个）
第 3 颗星3 个 Boss 同时出现（1 波）
第 4 颗星起之后每颗星都是 3 个 Boss 同时出现（1 波），星数无上限

Boss 相邻两波不会重复出场，只是顺序打乱。死亡结算会显示「无尽第 N 颗星」。

五、技术说明

核心原则：原版代码一行不动

所有新功能都写在 v2-extension.js 里，以「追加脚本」的形式挂在原版后面。 它通过读取原版的全局状态（player / fishes / score / lives） 和挂钩几个函数来接入：

drawPlayer     → 画 Boss、子弹、蛇形线、玩家皮肤
drawFish       → 加镜头偏移（地图放大用）
drawBackground → 每帧最先更新镜头
spawnFish      → 新鱼生成在视野边缘 + 体型缩小
setPointer     → 屏幕坐标 → 世界坐标换算
updateHud      → 命数越界兜底（防崩溃）
endGame        → 拦截「长到体型就通关」
playEat / beep → 音量调整

好处是：以后你更新原版游戏，只要把扩展层重新拼一次就行，不会跟原版改动打架。

地图放大是怎么做的

原版的可玩区域就是整块屏幕。v2 把 W/H 改成指「世界尺寸」（屏幕的 1.45 倍）， 绘制鱼 / 玩家 / 子弹时统一平移 -cam，背景固定在屏幕上铺满， 指针坐标按「屏幕 → 世界」换算。所以空间变大了，但原版的操控手感不变。

体积优化

原版素材 3078 KB → 单个游戏文件 768 KB。做法：7 张 PNG 全部转 WebP、 去掉一张重复的贴图、皮肤按不透明面积归一化到 256px。

六、注意事项

① Boss 出场音效的来源
用的那段 2.7 秒音频提取自你提供的抖音「原声」页（作者：@墨夏汐）。自己玩、发朋友圈没问题， 如果要商用（做广告、上架应用、卖周边）请先取得授权，或者换成免版税音效库里的素材。

② 图片素材
魔芋爽包装、高等数学封面、外卖袋这些图带有品牌元素。 同样地：非商业自用没问题，商用前要确认授权，或替换成自己画的相似造型。

③ 皮肤与角色的统一性
10 套皮肤共用同一只角色（同姿态、同大小、同材质），只靠上衣和尾巴造型区分 —— 保证商店里排一排看起来是同一个角色的不同状态。
