# 神金海豹大作战（Tun Tun Da Zuo Zhan）

> 一只靠「吞」变强的海豹，在奶龙海里吃出一条血路的单文件网页小游戏。🐟

《神金海豹大作战》是一款 **吃掉比你小的、躲开比你大的** 的吞噬成长类休闲游戏。在原版玩法基础上做加法：保留原版手感与音效，新增了**积分 / 皮肤 / Boss 战 / 冲刺 / 水波攻击 / 局内进化 / 无尽模式 / 云存档与排行榜** 一整套系统，最终打包成一个**双击即玩、断网也能跑**的单个 HTML 文件。

- 🎮 在线试玩：<https://seal-battle.app.workbuddy.host/>
- 📦 当前版本：**V0.5 · M12**（2026-10-27）
- ☁️ 支持 WorkBuddy 云服务登录、微信登录、个人资料和无尽模式排行榜；联网时可使用，断网仍可直接游玩。
- 📱 手机与电脑双端适配：世界尺寸按屏幕自动放大（手机 ×3.0 / 电脑 ×1.45），镜头跟随主角。

> ⚠️ GitHub 网页版不会渲染仓库里的 `.html` 文件（点开只会看到源码）。想直接玩请用上面的**在线试玩**链接，或把 `游戏/神金海豹大作战_v2.html` 下载到本地后双击打开。

## 一、快速开始

### 只想玩 / 发给朋友

打开 `游戏/神金海豹大作战_v2.html` 即可：

- 电脑：双击文件，或拖进浏览器窗口
- 手机：把文件传到微信、用浏览器打开
- 在线：<https://seal-battle.app.workbuddy.host/>

游戏主体可离线运行；云登录、个人资料和排行榜等功能需要网络。`游戏/wb-cloud-sdk.js` 是云服务 SDK 文件，移动或发布游戏时请与 HTML 放在一起。

### 想改内容

所有新增功能都写在 `源码/v2-extension.js`（扩展层），原版代码一个字没动。改数值 / 文案 / 皮肤价格，直接搜索对应配置即可：

| 想改什么 | 在哪找 |
| --- | --- |
| 皮肤名字 / 价格 / 稀有度 | `SKINS = [ ... ]` |
| Boss 名字 / 血量 / 攻击 / 方块（核心物） | `BOSS_DEFS = [ ... ]` |
| 局内进化的 9 种强化 | `UPGRADES = [ ... ]` |
| 水波攻击伤害 / 冷却 / 半径 | `SPIN_ATK = { cd, dmg, dur }` |
| 体型上限 / 地图大小 / 鱼的大小 | `WIN_CAP` / `worldScale()` / `FISH_SCALE` |
| 难度参数（成长 / 刷怪） | `DIFFS = { easy, hard, hell }` |
| 普通 / 无尽积分倍率 | `COIN_MUL` / `ENDLESS_COIN_MUL` |
| 清屏冷却（wjh） | `CLEAR_CD`（60 秒） |

改完用 `python _sync9.py` 把扩展层合并进 HTML 与发布副本，或先跑 `node --check 源码/v2-extension.js` 做语法检查。

## 二、玩法

### 基础操作

| 操作 | 说明 |
| --- | --- |
| **移动** | 鼠标 / 手指**按住拖动**，海豹跟着光标游（拖动不会误放技能） |
| **水波攻击** | **单指轻点屏幕**（位移 < 16px、时长 < 230ms）或点右下「水波」按钮；对贴身 Boss 造成伤害 |
| **冲刺** | **双击屏幕** / 按 `SPACE` / 点右下技能按钮，朝当前方向瞬冲并附带无敌；冷却随「闪充」进化缩短 |
| **吞噬** | 吃掉比你小的奶龙就能变大；比你大的会咬你、掉血 |
| **进化** | 吃鱼攒经验，升级弹出「三选一」，选卡期间无敌 |
| **打 Boss** | 水波输出 + 抢吃 Boss 身边的方块（核心物），三只 Boss 全部击败才算通关 |
| **设置** | 右上角 ⚙：音量、怪物生成速度、正式版/测试版切换 |
| **云服务** | 登录（邮箱 / 微信）后同步个人资料，并查看无尽模式排行榜；未登录也可正常游玩 |

### 三个 Boss

| 顺序 | Boss | 血量 | 方块（核心物） | 技能 |
| --- | --- | --- | --- | --- |
| 1 | 袋鼠 DJ | 80 | 3 个音响（每吃 1 个扣 1/3 血） | 音浪环 —— 红色声波扩散，走位穿过 |
| 2 | 魔芋爽辣王 | 120 | 4 个辣条（吃光全部 → 扣当前血量一半，10 秒后重生） | 辣油散射 —— 整圈向外放射辣条 |
| 3 | 高数压轴 | 160 | 5 个课本（吃光全部 → 扣当前血量一半，10 秒后重生） | 函数引力 + 积分号弹幕 |

- 方块分「护盾态 / 可吃态」循环，变成绿色发光并弹出「吃掉它!」时才能吃，撞到护盾态会扣血。
- 玩家主要输出是**旋转水波**：基础 12 伤、冷却 5.5 秒，「水波强化」每级 +7 伤。
- Boss 血条置顶显示当前血量最低的 Boss，名称与数字同步。
- 受击后无敌 2.4 秒；「疗愈」进化立刻回复 30 滴血。

### 通关规则

长到目标体型**不会直接通关**——必须把 3 个 Boss 全部击败才算赢。打完所有 Boss 会解锁传说皮肤 **wjh**。

### 无尽模式

打完 3 个普通 Boss **不结束**，进入「无尽星数」循环，打到死为止看你能冲几颗星：

- 第 1 颗星：随机 1 个 Boss
- 第 2 颗星：2 个 Boss 同时出现，重复 3 轮
- 第 3 颗星：3 个 Boss 同时出现
- 第 4 颗星起：每颗星都是 3 个 Boss，**星数无上限**

Boss 相邻两波不会重复出场。死亡结算会显示「无尽第 N 颗星」以及你的**历史最高星数**。

### 难度与积分倍率

| 难度 | 普通模式 | 无尽模式 |
| --- | --- | --- |
| 简单 | 1.0× | 2.0× |
| 困难 | 1.5× | 2.5× |
| 地狱 | 2.0× | 3.0× |

三个难度的初始血量统一为 **100 滴**，难度只影响刷怪、成长速度与积分倍率。

## 五、技术说明

- **单文件交付**：图片、音频、SDK 全部内联进 HTML，断网可运行；文件约 1.4 MB。
- **分层架构**：原版核心逻辑（HTML 内的原版 `<script>` 段）保持不动，所有新增功能通过 monkey patch 挂在扩展层，出问题可单独回滚扩展层。
- **性能**：渐变缓存、辉光贴图预渲染（替代 `shadowBlur`）、视口裁剪、粒子上限 320、HUD 15Hz 节流；桌面 160 fps+。
- **存档**：`localStorage` 双键备份 + 结构自愈 + 300ms 防抖，隐私模式或配额满时不会崩。
- **调试入口**：控制台 `window.__v2` 可访问 `V`（局内状态）、`S`（存档）、`player`、`spawnBoss`、`damageBoss`、`trySpinAttack`、`m6StartSkill` 等。
