# 神金海豹大作战（Tun Tun Da Zuo Zhan）

> 一只靠「吞」变强的海豹，在奶龙海里吃出一条血路的单文件网页小游戏。🐟

《神金海豹大作战》是一款 **吃掉比你小的、躲开比你大的** 的吞噬成长类休闲游戏。在原版玩法基础上做加法：保留原版手感与音效，新增了**积分 / 皮肤 / Boss 战 / 冲刺 / 局内进化 / 无尽模式** 一整套系统，最终打包成一个**双击即玩、断网也能跑**的单个 HTML 文件。

- 🎮 在线试玩：<https://shenjin-seal.app.workbuddy.host/>
- 📦 当前版本：**V0.4**

## 一、快速开始

### 只想玩 / 发给朋友

打开 `游戏/神金海豹大作战_v2.html` 即可：

- 电脑：双击文件，或拖进浏览器窗口
- 手机：把文件传到微信、用浏览器打开

单文件自带全部图片与音效，**无需联网、无需安装**。

### 想改内容

所有新增功能都写在 `源码/v2-extension.js`（扩展层），原版代码一个字没动。改数值 / 文案 / 皮肤价格，直接搜索对应配置即可：

| 想改什么 | 在哪找 |
| --- | --- |
| 皮肤名字 / 价格 / 稀有度 | `SKINS = [ ... ]` |
| Boss 名字 / 技能 / 攻击间隔 | `BOSS_DEFS = [ ... ]` |
| 局内进化的 8 种强化 | `UPGRADES = [ ... ]` |
| 体型上限 / 地图大小 / 鱼的大小 | `WIN_CAP` / `worldScale()` / `FISH_SCALE` |
| 难度参数（命数 / 成长 / 刷怪） | `DIFFS = { easy, hard, hell }` |
| 普通 / 无尽积分倍率 | `COIN_MUL` / `ENDLESS_COIN_MUL` |

## 二、玩法

### 基础操作

| 操作 | 说明 |
| --- | --- |
| **移动** | 鼠标 / 手指拖动，海豹跟着光标游 |
| **吞噬** | 吃掉比你小的奶龙就能变大；比你大的会咬你、掉命 |
| **冲刺** | 双击屏幕或按 `SPACE`，朝当前方向瞬冲，附带 3 秒无敌，冷却 10 秒 |
| **进化** | 吃鱼攒经验，升级弹出「三选一」，选卡期间无敌 |
| **打 Boss** | Boss 身边有 3 个核心物，等它变绿弹出的 2.2 秒冲上去吃掉，就是唯一输出窗口 |
| **设置** | 右上角 ⚙：音量、怪物生成速度、正式版/测试版切换 |

### 三个 Boss

| 顺序 | Boss | 核心物 | 技能 |
| --- | --- | --- | --- |
| 1 | 袋鼠 DJ | 音响 | 音浪环 —— 红色声波扩散，走位穿过 |
| 2 | 魔芋爽辣王 | 辣包 | 辣油散射 —— 8~17 发子弹整圈放射 |
| 3 | 高数压轴 | 答案卷 | 蛇形函数线 —— 发光的正弦曲线追着你跑 |

### 通关规则

长到目标体型**不会直接通关**——必须把 3 个 Boss 全部击败才算赢。打完所有 Boss 会解锁传说皮肤 **wjh**。

### 无尽模式

打完 3 个普通 Boss **不结束**，进入「无尽星数」循环，打到死为止看你能冲几颗星：

- 第 1 颗星：随机 1 个 Boss
- 第 2 颗星：2 个 Boss 同时出现，重复 3 轮
- 第 3 颗星：3 个 Boss 同时出现
- 第 4 颗星起：每颗星都是 3 个 Boss，**星数无上限**

Boss 相邻两波不会重复出场。死亡结算会显示「无尽第 N 颗星」以及你的**历史最高星数**。

### 难度与积分倍率

| 难度 | 普通模式 | 无尽模式 |
| --- | --- | --- |
| 简单 | 1.0× | 2.0× |
| 困难 | 1.5× | 2.5× |
| 地狱 | 2.0× | 3.0× |

## 五、技术说明

### 核心原则：原版代码一行不动

所有新功能都写在 `源码/v2-extension.js` 里，以「追加脚本」的形式挂在原版后面。它通过读取原版全局状态（`player` / `fishes` / `score` / `lives`）和挂钩几个函数来接入：

```
drawPlayer     → 画 Boss、子弹、蛇形线、玩家皮肤
drawFish       → 加镜头偏移（地图放大用）
drawBackground → 每帧最先更新镜头
spawnFish      → 新鱼生成在视野边缘 + 体型缩小
setPointer     → 屏幕坐标 → 世界坐标换算
updateHud      → 命数越界兜底（防崩溃）
endGame        → 拦截「长到体型就通关」
playEat / beep → 音量调整
```

好处是：以后更新原版游戏，只要把扩展层重新拼一次即可，不会与原版改动打架。

### 地图放大

原版可玩区域就是整块屏幕。v2 把 `W/H` 改成指「世界尺寸」，绘制鱼 / 玩家 / 子弹时统一平移镜头，背景固定在屏幕铺满，指针坐标按「屏幕 → 世界」换算——空间变大了，操控手感不变。手机端自动放更大（3.0×），电脑端 1.45×。

### 体积优化

原版素材约 3 MB，压缩成单个游戏文件约 800 KB。做法：7 张 PNG 转 WebP、去掉一张重复贴图、皮肤按不透明面积归一化到 256px。

## 七、构建

需要 Python 3 + Pillow：

```bash
pip install pillow
python3 源码/merge.py
```

脚本会自动：贴图转 WebP 压缩 → 抠底裁边 → 把扩展层注入原版 → 输出单文件游戏。

> 说明：`merge.py` 里引用的是原作者环境的绝对路径（`/root/uploads/...`、`/workspace/...`），当前仓库的 `游戏/神金海豹大作战_v2.html` 已是构建产物，日常改动直接编辑该文件与 `源码/v2-extension.js`（两者保持同步）即可，无需重新跑 merge。
