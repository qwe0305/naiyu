01原玩法拆解：吞噬成长类为什么容易上手、也容易腻

核心循环

一个极短的闭环，通常 8~15 秒就能跑一轮：

1移动单摇杆 / 鼠标 / 手指拖动，零学习成本
2吞噬碰到比自己小的食物或敌人就吃掉，体积、分数立即上涨
3变大体积增长带来"我变强了"的即时正反馈
4吃更大的原本追着你跑的敌人，现在反过来被你一口吞掉

爽点在哪

  • 即时反馈极强——每一次吞噬都有体积、分数、音效、粒子四重反馈。
  • 滚雪球快感——"从被追赶到碾压全场"的翻转，是这类游戏的核心情绪。
  • 上手门槛为零——不用教学，看三秒就会玩，极其适合短视频信息流投放。
  • 单局超短——30 秒到 3 分钟，天然适配碎片时间与"再来一局"。

但问题也很明显

问题后果
缺少高潮点一条平缓的曲线，玩到后面只是在"刷数字"，没有紧张感峰值，也记不住任何瞬间。
没有成长系统每局从零开始，玩家攒不下任何东西，"我变强了"的感知只存在于单局内。
没有目标感没有 Boss、没有关卡、没有成就，玩家不知道"玩到什么时候算赢"。
没有社交钩子没有分享、没有排行、没有炫耀点，天然缺少自传播。
变现触点少没有可消耗的货币、没有皮肤、没有"看广告换奖励"的动机。
本方案的整体思路：保留原游戏"零门槛 + 即时爽感"的骨架不动， 在它上面装三根新柱子——一个 Boss（高潮点）、一套积分皮肤（长线目标）、 一组日常系统（留存与传播）。

02Boss 方案：3 个 Boss 的 Boss Rush

单局改成 「打穿 3 个 Boss 才算通关」 的关卡结构：第 1 个 Boss 在 42 秒登场， 击败后 12 秒下一个接上，血量、体积、移动速度、攻击频率逐级递增。

三个 Boss 共用同一个核心机制——吃掉它的"核心物"就能破防—— 但核心物、弹幕形态、战斗节奏完全不同，保证三关打起来是三种手感。

你发的那张黄色袋鼠图，我已经处理好了：去掉白底、裁掉多余留白、羽化边缘， 生成了 Boss 精灵图（420px）和头像（128px），直接用在游戏里。

核心机制：吃掉它的核心物

这是整个 Boss 战的灵魂，三个 Boss 通用。3 个核心物绕着 Boss 转圈，在两种状态间循环"换碟"：

护体期 ≈ 4.6 秒 核心物贴身高亮红色 挂着护盾，此时撞上去会被反伤掉血，只能躲。
弹出期 ≈ 2.2 秒 核心物脱离本体、向外漂 变绿、发光、头顶弹出「吃掉它！」提示——这是唯一的输出窗口。
吃掉 = 进阶 Boss 少一个核心物 核心物被吞掉后 Boss 进入下一阶段：移动更快、出手更频繁，逼着玩家再抓下一次机会。
为什么这样设计：它把"无脑吃"升级成了"看节奏、抓时机"。 玩家第一次打会贪，被电到掉血；第二次就学会"等它变绿再冲"。 一个 Boss 教会了玩家一个新技巧——这就是"关卡"的意义。
同时核心物 = 可视化进度条，玩家一眼就知道"还差几个"。

吃掉之后奖励什么

如果吃掉核心物只是"没反应"，玩家不会想做第二次。所以每次吞掉一个核心物，玩家立刻获得持续约 10 秒的 【核心之力】：

  • 磁铁（240 范围内食物自动飞向你）
  • 加速（移动速度 +55%）
  • 双倍分（所有得分 ×2）
  • 破格吞噬（普通状态下只能吃比你小的敌人，此时可以吃掉比你大的）
收益设计：吃核心物不只是"打 Boss 的进度"，它本身就是一个超强 Buff。 于是玩家面对的问题是——我要不要为了这个 Buff 冒险冲进去？ 风险和收益同时拉满，这才是好玩的决策。

难度曲线原则：第 1 关必须"能教会玩家"，而不是"能难住玩家"。 所以 Boss 1 的护卫期最长、弹幕最慢，玩家第一次贪上去被电一次，第二次就学会了——先教学，再考试。

03玩法升级 · v2.0

原版只有「移动 + 吞噬」两个动作，玩久了会觉得操作空间太小、没有技术门槛。 v2.0 加了三层新东西，把"无脑吃"变成"有操作的吃"。

1. 冲刺 Dash —— 让操作有技术含量

触发SPACE / 双击屏幕朝当前移动方向瞬冲，0.22 秒内速度 ×3.2，并获得 3 秒无敌
冷却3 秒HUD 右下角圆形按钮实时显示冷却读秒，冷却中会变暗
用途躲弹幕 · 抢窗口躲音浪环、穿过辣油弹幕、抢 Boss 核心物弹出的 2.2 秒窗口

有了冲刺，「吃音响」就从运气行为变成了可以练习的技术动作—— 这是让玩家愿意"再来一局"的关键。

2. 局内进化 —— 每局都不一样

选卡期间无敌：升级弹窗弹出时世界会暂停，但「弹出瞬间」和「选完恢复的那一帧」 玩家很可能正贴着大鱼或 Boss，容易出现"刚选完就掉命"的挫败感。 因此选卡全程无敌，选完回到游戏还会保留 1.6 秒无敌缓冲，玩家身上会亮起金色光环。

吃食物、吃敌人会累积经验，升到 2~9 级时游戏暂停并弹出「三选一」进化卡， 选中的强化本局永久生效。8 种进化里随机抽 3 张：

进化效果为什么这样设计
巨化体积 +12%直接变强，也让你更容易被大团子盯上，风险同步上升
疾风移动速度 +15%走位流的核心，躲弹幕更从容
吸星磁吸范围 +45%滚雪球加速，适合"吃就完事"的打法
暴食可以吞下更大的敌人把"躲"变成"吃"，改变整局的风险收益判断
连击大师连击倍率上限 +1奖励不断手的激进玩法，配合音效反馈很爽
铁壁生命立刻回满 + 5 秒无敌容错型选择，新手也能明显感到变强
闪充冲刺冷却 −0.6 秒让冲刺从"应急手段"变成"常规操作"
丰收吃食物额外 +1 经验加速升级曲线，越早拿收益越高
设计意图：同一套操作，每一局能走出不同的 build。 这等于用零美术成本拿到了 roguelite 的重复可玩性 —— 也是最适合网页小游戏的性价比方案。

3. 地图放大 + 镜头跟随

原版的可玩区域就是整块屏幕，空间偏紧。v2 把世界放大到屏幕的 1.45 倍， 镜头跟着海豹走，活动空间和鱼的分布范围都变大了；同时把除 Boss 外的奶龙整体缩小 15%， 画面更透气。做法上仍然零侵入原版：W/H 改指世界尺寸，绘制鱼/玩家/子弹时统一平移镜头， 背景固定在屏幕上铺满，指针坐标按「屏幕 → 世界」换算。

4. Boss Rush —— 把"无限刷分"变成"一局有终点"

原来打完一个 Boss 就结束了，单局缺一个明确的通关目标。 现在改成 连打 3 个 Boss 才算通关，难度、体积、攻击频率逐级递增：

0 ~ 42 秒发育期吞噬成长、随手吃道具、升到 3~5 级，为 Boss 战攒底子
第 1 关袋鼠 DJ最简单，用音浪环"教"会玩家怎么躲、怎么抢核心物
第 2 关魔芋爽辣王辣油散射弹幕，逼玩家用冲刺穿缝隙
第 3 关高数压轴蛇形函数线贴着你游过来，被扫到就掉血，只能靠走位和冲刺甩开，最终考验
通关规则（v2 调整）：长到目标体型不再直接通关 —— 体型到顶只是停住（此时体型约为 Boss 的 54%）。 必须把 3 个 Boss 全部击败才算通关：第 1 关打完 1 个 Boss 才算过关， 第 2 关累计 2 个，第 3 关累计 3 个。想跳过 Boss 直接刷分是行不通的。

击败后 12 秒下一个 Boss 接上——这个间隔刚好够玩家喘口气、吃几口食物， 又不会掉紧张感。通关后解锁传说皮肤【wjh】。

皮肤是怎么做出来的（已完成）

你给的那张黄色小生物图被定为初始模型，其余 9 套则用 "图生图"换装的方式，让同一个初始模型分别穿上每套衣服。 制作时严格守住三条规范：

  • 姿态与短尾对齐原图——保持角色原本的直立姿态，左下那根短尾的形状、长度、朝向原样保留， 不拉长、不变成鱼尾（做法是先把参考图校正到正确角度再喂给模型）
  • 光滑卡通材质——像动画电影角色那样表面光滑细腻，没有毛绒 / 绒毛 / 布料纤维质感
  • 只穿上衣，不穿裤子——保持整个系列的一致性

统一性是怎么保证的：所有皮肤共用同一张角色参考图（原图校正过角度）， 生成后用按不透明面积归一化的方式统一视觉大小，再统一抠白底 → 裁边 → 缩放到 256px → 以 WebP 内联进游戏（单文件仅 230 KB）。 所以无论换上哪件衣服，角色在商店和游戏里都是同一个大小、同一种质感。

这样做的好处是：6 个皮肤看起来是同一个角色的不同状态， 而不是 6 个互不相干的图。后续要加新皮肤，只要再给一张衣服图就行， 扩展成本几乎为零 —— 皮肤 = 服装包。

想换图 / 改价 / 改名字？
把新图按 皮肤id.png 的命名丢进 assets/skins/， 或直接改 src/game-src.html 里的 SKINS 数组 （name 名字 / price 价格 / rare 稀有度 1~4 / label 副标题）， 然后跑一次 python3 build.py 即可，几秒出新版本。
详细规格见 assets/skins/README.txt。

06分享与传播设计（网页版）

你提到"在抖音，记录美好生活"——这句话不该只是印在图上，它应该是一条完整的传播链。 网页版不需要抖音 SDK，靠一张图 + 一段文案 + 一个链接就能跑通：

A高光时刻吃掉音响 / 吃掉 Boss 的瞬间，就是天然的短视频素材（有动作、有反转、有字幕）。
B战报卡自动生成竖版 720×1000 战报图，带分数、连击、皮肤头像和 slogan，直接当视频封面或图文封面。
C挑战文案一键复制的挑衅式文案："我把袋鼠 DJ 的音响吃了，你敢吗？"——比"我得了 6930 分"传播力强得多，可发任意平台。
D链接回流把游戏部署到一个网址，朋友点开直接玩，不用下载、不用登录，形成闭环。
网页版要做的三件小事（都不影响现有玩法代码）： 1）把 index.html 传到一个静态托管（如对象存储 / Vercel / GitHub Pages），拿到一条网址； 2）加一点数据埋点（开始 / 结算 / 吃到音响 / 分享），用来看留存和分享率； 3）如果要"强制分享后领奖励"，网页版做不到自动验证，改成"分享即送"或"分享按钮点了就送"即可。

09风险提示

版权是最大的一条。 1）袋鼠形象如果来自第三方 IP（毛绒玩具/动画角色），正式上线前必须确认授权或重绘一个"神似但不同"的原创形象； 2）BGM 同理，抖音原声≠可商用素材。
这两条建议在 P1 阶段就解决，别拖到上线才发现。
  • 难度曲线——Boss 三阶段要逐步加压，第一阶段必须能"教"会玩家吃音响，否则留存会在第一次 Boss 战崩掉。
  • 数值膨胀——体积上限、分数上限要有天花板，否则后期分数失去意义。
  • 公平性——皮肤绝不能加数值，否则排行榜和分享都会失去公信力。
  • 单局时长——建议控制在 90~150 秒，别超过 3 分钟，这是网页休闲小游戏的黄金区间。
